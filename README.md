# Code Review Checklist

A systematic checklist for reviewing code changes across functionality, maintainability, security, performance, and testing.

## Review stages

1. Understand the requirements, context, and changed files.
2. Verify functionality, edge cases, and error handling.
3. Assess readability, naming, structure, and complexity.
4. Check input validation, sensitive data, authentication, and authorization.
5. Look for performance problems, resource leaks, and inefficient database access.
6. Confirm meaningful tests cover expected behavior and failure cases.

## Usage

Use this skill during pull request reviews, code audits, team review process design, or developer onboarding. Work through the checklist in proportion to the change's risk and scope.

A checklist is a prompt for careful review, not proof that code is correct. Validate important findings against the actual implementation and test behavior before reporting them.
